# kronotech.ru — техническая документация проекта

Закрытый рабочий репозиторий компании «Кронотэк» для хранения журналов переноса и технических отчётов по сайту [kronotech.ru](https://kronotech.ru/).

## Что находится в репозитории

В папке [`www`](www/) собраны:

- основной журнал переноса сайта с Hostland на REG.RU;
- хронология выполненных действий и найденных сложностей;
- план переноса и план отката;
- чек-лист приёмки;
- паспорт площадок без паролей;
- комплексный аудит тестового сайта;
- единый отчёт в формате DOCX;
- HTML-оглавление документов.

Начинать просмотр следует с [`www/00-CHTO-GDE-LEZHIT.md`](www/00-CHTO-GDE-LEZHIT.md). Самый актуальный подробный документ — [`www/2026-08-25-perenos-hostland-na-reg-ru-testovyy-domen-codex.md`](www/2026-08-25-perenos-hostland-na-reg-ru-testovyy-domen-codex.md).

## Что намеренно не хранится

Репозиторий не предназначен для хранения:

- паролей, API-токенов и SSH-ключей;
- файлов конфигурации с доступами;
- резервных копий и дампов базы данных;
- полных архивов сайта;
- пользовательских данных и содержимого заявок.

Резервные копии хранятся отдельно от технической документации.

## Текущее состояние

Перенос на REG.RU выполнен. Основной домен — `kronotech.ru`. В журнале зафиксированы последующие проверки и исправления: `robots.txt`, `.htaccess`, Метрика, формы и цели, микроразметка, изображения, мобильное меню, скорость загрузки и отображение характеристик проектов.

Последнее подтверждённое исправление: на внутренних страницах проектов значение года отображается над подписью «год» и не обрезается на компьютере и мобильном экране.
